## Artifacts this phase produces

This plan implements the vector embedding pipeline, Matryoshka truncation, normalization, and test suite:

### Classes & Engines (`packages/graph/src/embedding/embedder.ts`)
- `ArgonEmbedder`: Core embedding engine supporting local ONNX CPU execution (`onnx-community/embeddinggemma-2-ONNX`) and transparent Google Gemini fallback (`text-embedding-004`)

### Functions & Mathematical Utilities
- `formatInput`: Formats query vs document text with required task-specific prefixes
- `processMatryoshkaVector`: Slices embeddings to 512 dimensions and re-normalizes using strict unit L2 norm ($L_2 = 1.0$)
- `cosineSimilarity`: Dot product calculation for normalized vector similarity comparison

### TypeScript Types & Interfaces (`packages/graph/src/embedding/types.ts`)
- `EmbeddingProvider`: Union type `'local' | 'gemini' | 'auto'`
- `EmbedderConfig`: Configuration interface for provider, model, cache directory, API keys, and target dimensions
- `EmbedResult`: Typed result interface containing vector, dimension, provider, and model metadata

### Files Created
- `packages/graph/src/embedding/embedder.ts`: `ArgonEmbedder` implementation with MRL truncation, L2 normalization, and fallback
- `packages/graph/src/embedding/types.ts`: TypeScript contracts for embedder configuration and responses
- `packages/graph/test/embedding.test.ts`: Vitest unit test suite verifying dimension (512), unit L2 norm, and semantic clustering sanity
