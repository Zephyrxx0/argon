       - `UPDATE_JOB_STATUS`:
         `MERGE (j:IngestJob {id: $jobId}) SET j.repo_url = $repoUrl, j.status = $status, j.progress = $progress, j.error = $error, j.updated_at = $updatedAt, j.started_at = coalesce(j.started_at, $startedAt)`
       - `BATCH_MERGE_PERSONS`:
         `UNWIND $batch AS row MERGE (p:Person {id: row.id}) ON CREATE SET p.name = row.name, p.email_hash = row.id`
       - `BATCH_MERGE_FILES`:
         `UNWIND $batch AS row MERGE (f:File {path: row.path})`
       - `BATCH_MERGE_PULL_REQUESTS`:
         `UNWIND $batch AS row MERGE (pr:PullRequest {id: row.id}) SET pr.title = row.title, pr.merged_at = row.merged_at, pr.is_revert = row.is_revert`
       - `BATCH_MERGE_COMPONENTS`:
         `UNWIND $batch AS row MERGE (c:Component {name: row.name})`
       - `BATCH_MERGE_DECISIONS`:
         `UNWIND $batch AS row MERGE (d:Decision {id: row.id}) SET d.title = row.title, d.status = row.status, d.valid_from = row.valid_from, d.valid_to = row.valid_to, d.source_url = row.source_url, d.source_kind = row.source_kind, d.summary = row.summary, d.embedding = row.embedding, d.embedding_model = 'embeddinggemma-2'`
       - `BATCH_EDGES_TOUCHES`:
         `UNWIND $batch AS row MATCH (pr:PullRequest {id: row.pr_id}), (f:File {path: row.file_path}) MERGE (pr)-[:TOUCHES]->(f)`
       - `BATCH_EDGES_AUTHORED`:
         `UNWIND $batch AS row MATCH (p:Person {id: row.author_id}), (pr:PullRequest {id: row.pr_id}) MERGE (p)-[:AUTHORED]->(pr)`
       - `BATCH_EDGES_IN_COMPONENT`:
         `UNWIND $batch AS row MATCH (f:File {path: row.file_path}), (c:Component {name: row.component_name}) MERGE (f)-[:IN_COMPONENT]->(c)`
       - `BATCH_EDGES_DEPENDS_ON`:
         `UNWIND $batch AS row MATCH (c1:Component {name: row.source}), (c2:Component {name: row.target}) MERGE (c1)-[r:DEPENDS_ON]->(c2) SET r.weight = row.weight, r.count = row.count`
       - `BATCH_EDGES_REVERTS`:
         `UNWIND $batch AS row MATCH (pr1:PullRequest {id: row.revert_id}), (pr2:PullRequest {id: row.reverted_id}) MERGE (pr1)-[:REVERTS]->(pr2)`
       - `BATCH_EDGES_SUPERSEDES`:
         `UNWIND $batch AS row MATCH (d1:Decision {id: row.source_id}), (d2:Decision {id: row.target_id}) MERGE (d1)-[:SUPERSEDES]->(d2)`
       - `BATCH_EDGES_GOVERNS`:
         `UNWIND $batch AS row MATCH (d:Decision {id: row.decision_id}), (c:Component {name: row.component_name}) MERGE (d)-[:GOVERNS]->(c)`
