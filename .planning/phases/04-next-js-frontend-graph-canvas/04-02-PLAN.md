<threat_model>
### ASVS Level 1 Controls & Threat Mitigations

| Threat ID | Threat Description | Severity | ASVS Category | Mitigation Strategy |
|---|---|---|---|---|
| **T-04-03** | SSRF / Malicious Git URL Injection in Ingest Modal | High | V5.1 Input Validation | Validate git URLs on the client against standard HTTPS / git protocol patterns (`/^https?:\/\/[a-zA-Z0-9_.-]+(\/.*)?$/`), rejecting `file://`, private IP ranges, or command injection characters before sending to the backend worker. |
| **T-04-04** | State spoofing via unvalidated contributor ID | Low | V13.1 Generic Data Validation | Contributor IDs are opaque string hashes matching FalkorDB `(:Person { id })` nodes; validate presence in workspace contributor list before setting. |
</threat_model>
