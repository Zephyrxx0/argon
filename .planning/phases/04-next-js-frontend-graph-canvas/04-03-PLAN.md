<read_first>

<action>
1. Create `apps/web/app/api/briefing/route.ts`:
   - Validates JSON body with Zod:
     ```ts
     const BriefingRequestSchema = z.object({
       task: z.string().min(1),
       workspaceId: z.string().regex(/^[a-zA-Z0-9_-]+$/).default('default'),
       files: z.array(z.string()).optional(),
       components: z.array(z.string()).optional(),
       contributorId: z.string().optional(),
       asOf: z.number().optional()
     });
     ```
   - Client auto-selection conforming to D-12:
     - If `process.env.GATEWAY_URL` is defined, instantiates `HttpGatewayClient({ baseUrl: process.env.GATEWAY_URL, secret: process.env.GATEWAY_SECRET })`.
     - Else, instantiates `DirectGraphGatewayClient(new ArgonGraphClient())`.
   - Calls `await runBriefingPipeline(client, validatedPayload)`.
   - Returns structured JSON response (`BriefingResponse`) with appropriate HTTP status codes:
     - 200 on success.
     - 200 with status `NO_GRAPH_DATA` or `CITATION_INTEGRITY_FAILURE` when graph yields no valid evidence.
     - 503 if FalkorDB times out or is unreachable.
     - 400 on Zod validation failure.
2. Write unit tests in `apps/web/tests/api-briefing.test.ts` testing successful synthesis, schema validation errors, and error propagation.
</action>
