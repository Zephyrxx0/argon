## Visuals & Hierarchy

- **Primary Visual Anchor / Focal Point:** The interactive split-pane workspace featuring the high-contrast Command Bar header and the dual-stream layout (Left: scrollable Briefing View stream; Right: sticky Cytoscape Graph Canvas).
- **Visual Hierarchy:**
  1. *Header Command Bar & Contributor Pill:* Instant access anchor for search and identity switching (`Cmd+K`).
  2. *Status & Kill-Switch Alerts:* High-contrast diagnostic banner (`#ff0055` red or `#00f0ff` cyan) commanding immediate attention on state change.
  3. *Interactive Cytoscape Canvas:* Living topological visualization with pulsing directed traversal edges and node type color signatures.
  4. *Evidence Cards Stream:* Structured narrative claim cards with glowing category badges (`DECISION` in warning gold `#ffb800`, `COMPONENT` in cyan `#00f0ff`, `FILE` in blue `#58a6ff`, `PERSON` in purple `#bc8cff`).

| Error state (Citation Failure) | No Graph, No Answer: Refusing to present briefing because 0 verified graph citations could be proven for the generated claims. |
