<title>Build Cytoscape Canvas wrapper and dynamic 2077 stylesheet</title>
<read_first>

- .planning/phases/04-next-js-frontend-graph-canvas/04-CONTEXT.md

- packages/graph/src/queries/types.ts
</read_first>
<action>
1. Create `apps/web/components/canvas/stylesheet.ts`:
   - Exports `createCytoscapeStylesheet(tokens: ReturnType<typeof get2077ThemeTokens>)`:
     - Default node: font-family `var(--font-mono)`, font-size `11px`, text-color `#e6edf3`, border-width `2px`, background-color `#0d1117`.
     - `node[type = "Decision"]`: shape `diamond`, border-color `#ffb800` (warning gold).
     - `node[type = "Decision"][status = "superseded"]`: shape `diamond`, border-color `#ff0055` (red), border-style `dashed`.
     - `node[type = "Component"]`: shape `round-rectangle`, border-color `#00f0ff` (cyan), width `48px`, height `28px`.
     - `node[type = "File"]`: shape `rectangle`, border-color `#58a6ff` (blue), width `36px`, height `22px`.
     - `node[type = "Person"]`: shape `ellipse`, border-color `#bc8cff` (purple), width `32px`, height `32px`.
     - Default edge: curve-style `bezier`, target-arrow-shape `triangle`, line-color `#30363d`, target-arrow-color `#30363d`, width `1.5px`.
     - Class `.highlighted`: border-color `#00f0ff`, border-width `4px`, z-index `999`.
     - Class `.dimmed`: opacity `0.2`.
     - Class `.marching-edge`: line-color `#00f0ff`, target-arrow-color `#00f0ff`, line-style `dashed`.
2. Create `apps/web/components/canvas/cytoscape-canvas.tsx` (`'use client'`):
   - Registers `cytoscape-fcose` extension once.
   - Embeds Cytoscape instance inside a container `div` using `useRef`.
   - Runs `fcose` layout with options: `animate: true`, `animationDuration: 500`, `fit: true`, `padding: 40`.
   - Cleans up instance on unmount with `cy.destroy()` (mitigates T-04-07).
3. Write unit tests in `apps/web/tests/cytoscape-style.test.ts` verifying selector mapping and color definitions.
</action>

<action>
1. Create `apps/web/components/canvas/traversal-animator.ts`:
   - Manages requestAnimationFrame timer for pulsing highlighted edges and animating `line-dash-offset` along multi-hop paths.
   - Exports `startMarchingAnimation(cy, edgeIds)` and `stopMarchingAnimation()`.
2. Create `apps/web/components/canvas/node-inspector.tsx` (`'use client'`):
   - Renders a floating popover positioned above the clicked node:
     - Displays Node Label, FalkorDB ID (`#id`), Type badge, and properties.
     - Action: "Jump to Cited Claim" which calls `scrollIntoView` for the matching Evidence Card in the left panel.
3. Wire `useGraphSync` into `CytoscapeCanvas`:
   - On `hoveredNodeId` change: applies `.highlighted` to the hovered node and its neighbors; applies `.dimmed` to all other nodes.
   - On `focusRequest` change: smoothly animates Cytoscape camera to fit the requested node bounding box (`cy.animate({ fit: { eles, padding: 60 }, duration: 400 })`).
   - On Cytoscape node click: dispatches `setSelectedNode(node.id())`, opens `NodeInspector`, and triggers smooth scroll to the corresponding Evidence Card in the left panel.
4. Write integration test in `apps/web/tests/graph-sync.test.ts` verifying state synchronization.
</action>
