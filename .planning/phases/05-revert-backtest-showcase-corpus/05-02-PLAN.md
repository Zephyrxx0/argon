<title>Implement Baseline A (Naive Flat Vector Search) and Baseline B (Context-Constrained Raw LLM)</title>

- .planning/phases/05-revert-backtest-showcase-corpus/05-CONTEXT.md D-05, D-06, D-07
</read_first>
<action>
1. Create `packages/eval/src/baselines/naive-vector.ts` conforming to D-05 and D-06:
   - Define interface `DecisionCatalogEntry { id: string; title: string; summary: string; embedding: number[] }`.
   - `evaluateNaiveVectorCase(embedder: ArgonEmbedder, catalog: DecisionCatalogEntry[], fixture: RevertFixtureItem): Promise<CaseResult>`:
     - Formats query as `${fixture.revertSummary} ${fixture.touchedFiles.join(' ')}` with `formatInput(..., true)`.
     - Generates 512-d query embedding via `embedder.embed(query, true)` (or pre-computed/cached vector).
     - Computes cosine similarity against all decision embeddings in the catalog via `cosineSimilarity`.
     - Sorts descending with deterministic tie-breaking `b.score - a.score || a.id.localeCompare(b.id)` per T-05-06.
     - Calls `calculateCaseResult` with `method: 'naive-vector'`.
   - `runNaiveVectorBacktest(embedder: ArgonEmbedder, catalogMap: Map<string, DecisionCatalogEntry[]>, fixtures: RevertFixtureItem[]): Promise<{ results: CaseResult[]; summary: MethodSummary }>`.
2. Create `packages/eval/src/baselines/raw-llm.ts` conforming to D-05 and D-07:
   - `buildRawLlmPrompt(fixture: RevertFixtureItem, catalog: DecisionCatalogEntry[]): string`:
     - Injects commit summary, touched files, diff snippet, and an unstructured catalog dump of all decision titles and summaries.
     - Instructs model to identify governing decisions as of `fixture.revertTimestamp`.
   - `evaluateRawLlmCase(fixture: RevertFixtureItem, catalog: DecisionCatalogEntry[], cache: ReplayCache, options?: { allowLiveApi?: boolean }): Promise<CaseResult>`:
     - Checks `cache.get(prompt)`. If miss and `allowLiveApi && process.env.GEMINI_API_KEY`, calls Gemini via structured generator; otherwise falls back to deterministic mock response per T-05-04.
     - Validates returned IDs with Zod, passes to `calculateCaseResult` with `method: 'raw-llm'`.
   - `runRawLlmBacktest(catalogMap: Map<string, DecisionCatalogEntry[]>, fixtures: RevertFixtureItem[], cache: ReplayCache, options?: { allowLiveApi?: boolean }): Promise<{ results: CaseResult[]; summary: MethodSummary }>`.
3. Write unit/integration tests:
   - `packages/eval/test/baseline-vector.test.ts`: mocks catalog entries with known embeddings and asserts that naive vector search sorts purely by cosine similarity, ranking superseded decisions high when text matches (reproducing the real-world vector RAG flaw).
   - `packages/eval/test/baseline-llm.test.ts`: tests prompt construction, cached response retrieval, and metric calculation for raw LLM baseline.
</action>
