   - Revert PRs:
     - Revert #42: "Revert 'Linear Backoff on Gateway Timeout' (Incident #1042 Retry Storm)", `timestamp: 1686000000`, touches `["src/billing/retry.ts"]`, reverts commit #39.
     - Revert #58: "Revert 'Session Storage in Redis'", touches `["src/auth/session.ts"]`.
     - Revert #71: "Revert 'Unbounded Sync Queue'", touches `["src/sync/worker.ts"]`.
2. Create `packages/eval/src/seed.ts` conforming to D-10 and T-05-07:
   - `seedWorkspace(client: ArgonGraphClient, seedDataPath: string): Promise<{ workspaceId: string; nodeCount: number }>`:
     - Initializes schema using `initWorkspaceGraph(client, workspaceId)`.
     - Resets workspace graph cleanly (`MATCH (n) DETACH DELETE n`).
     - Executes parameterized Cypher `UNWIND` batches for:
       - Components: `UNWIND $batch AS c MERGE (:Component {name: c.name})`
       - Files: `UNWIND $batch AS f MERGE (file:File {path: f.path}) WITH file, f MATCH (c:Component {name: f.component}) MERGE (file)-[:IN_COMPONENT]->(c)`
       - Decisions: `UNWIND $batch AS d MERGE (dec:Decision {id: d.id}) SET dec.title = d.title, dec.status = d.status, dec.valid_from = d.valid_from, dec.valid_to = d.valid_to, dec.summary = d.summary, dec.source_url = d.source_url, dec.embedding = vecf32(d.embedding) WITH dec, d MATCH (c:Component {name: d.component}) MERGE (dec)-[:GOVERNS]->(c)`
       - `[:SUPERSEDES]` relationships: `UNWIND $batch AS edge MATCH (d1:Decision {id: edge.source_id}) MATCH (d2:Decision {id: edge.target_id}) MERGE (d1)-[:SUPERSEDES]->(d2)`
       - PullRequests & `[:REVERTS]`, `[:TOUCHES]` edges.
   - `seedAllShowcaseWorkspaces(client: ArgonGraphClient): Promise<Record<string, number>>`:
     - Discovers seed JSON files in `fixtures/seeds/` and seeds each workspace sequentially.
3. Write test `packages/eval/test/seed-synthetic.test.ts`:
   - Gated with `isFalkorLive` probe.
   - Seeds `synthetic-demo` and asserts:
     - Component count = 4, File count >= 8, Decision count >= 5.
     - `[:SUPERSEDES]` edge exists between `DEC-002` and `DEC-001`.
     - Vector index on `Decision.embedding` returns hits using `vecf32()`.
</action>
