## Visuals & Hierarchy

- **Primary Visual Anchor / Focal Point:** The HeaderBar identity cluster positioned immediately to the right of `ContributorPicker` (D-02), presenting seamless state transitions between anonymous guest browsing and authenticated GitHub session identity.
- **In-Place Auth Presentation (D-01):** GitHub authentication is presented in an in-place modal dialog (`AuthModal`) overlaid on top of the active Cytoscape graph canvas and briefing view (`bg-background/85 backdrop-blur-sm`). No full-page redirects or route unmounting occur, preserving in-flight queries and visual canvas layouts across session transitions.
- **Visual Hierarchy:**
  1. *HeaderBar Identity Trigger:* Displays either a subtle guest pill with a dedicated "Sign In" button (anonymous mode) or the user's GitHub avatar with handle `@login` and chevron (authenticated mode).
  2. *In-Place AuthModal Dialog:* Centered cyberpunk modal card (`max-w-md bg-card border border-border shadow-[0_0_60px_rgba(0,0,0,0.85)]`) with neon terminal header and high-contrast "Sign in with GitHub" CTA.
  3. *User Popover Menu:* Compact monospace dropdown displaying profile metadata (avatar, login, session type, workspace count) with clean separation of secondary actions ("Switch Account") and destructive actions ("Sign Out").
  4. *403 Forbidden Access Guard Banner:* High-visibility neon red card (`#ff0055`) displayed in place of briefing content when unauthorized workspace access is attempted, pairing clear diagnostic feedback with a "Switch to Showcase" recovery action.
