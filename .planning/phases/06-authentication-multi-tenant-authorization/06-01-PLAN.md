<threat_model>
### ASVS Level 1 Controls & Threat Mitigations

| Threat ID | Threat Description | Severity | ASVS Category | Mitigation Strategy |
|---|---|---|---|---|
| **T-06-01** | Session hijacking / cookie tampering | High | V3 Session Management | Use HTTP-only, secure, SameSite=Lax signed session cookies for Better Auth state and verify cryptographic HS256 signatures with `BETTER_AUTH_SECRET` (D-05, D-08). |
| **T-06-02** | Denial of Service via anonymous session exhaustion / phantom guest proliferation | Medium | V13 Generic Data Validation | AuthProvider checks for active session before invoking `signIn.anonymous()`, avoiding redundant guest minting on every render (RESEARCH §Pitfall 3). |
| **T-06-03** | XSS / Clickjacking in in-place auth dialogs and popovers | Medium | V5 Output Encoding & V14 Build and Deploy | Escape user identity strings (`login`, `avatar_url`), render dialogs within React root with Radix focus traps and backdrop blur, disallowing unvetted HTML injection (D-01, D-03). |
| **T-06-05** | JWT token tampering / algorithm confusion (`alg: none`) | High | V3 Session Management | Enforce strict HS256 protected header check with expiration (`exp: 15m`) and reject unverified or unsigned tokens. |
</threat_model>

<action>
1. In `apps/web/package.json`, add required dependencies:
   - `better-auth`: `^1.2.0`
   - `better-sqlite3`: `^11.8.0`
   - `@types/better-sqlite3`: `^7.6.12` (devDependency)
   - `jose`: `^5.9.0`
   - `@radix-ui/react-dialog`: `^1.1.6`
   - `@radix-ui/react-dropdown-menu`: `^2.1.6`
   - `@radix-ui/react-avatar`: `^1.1.3`
   Install packages using `pnpm --filter web install`.

2. Run user directive command to scaffold UI components:
   `npx shadcn@latest add @better-auth-ui/all --cwd apps/web --yes` (or create scaffolding files adhering to `@better-auth-ui` layout and styling if CLI runs in headless CI).

3. Create `apps/web/lib/auth.ts`:
   - Initialize Better Auth with `better-sqlite3` database engine at `process.env.AUTH_DB_PATH || path.resolve(process.cwd(), 'auth.sqlite')`.
   - Configure `secret` using `process.env.BETTER_AUTH_SECRET || 'argon-dev-secret-at-least-32-chars-long'`.
   - Configure GitHub social provider with `clientId: process.env.GITHUB_CLIENT_ID || ''` and `clientSecret: process.env.GITHUB_CLIENT_SECRET || ''`.
   - Register `anonymous({ emailDomainName: 'guest.argon.internal' })` plugin.
   - Register `jwt({ jwt: { sign: ... } })` plugin issuing HS256 signed JWTs with claims `{ userId: payload.sub, isAnonymous: Boolean(payload.isAnonymous) }`, 15-minute expiration (`setExpirationTime('15m')`), and standard `alg: 'HS256'` header using Web Crypto / `jose` `SignJWT` (D-05, D-06, D-08).

4. Create `apps/web/app/api/auth/[...all]/route.ts`:
   - Export `{ GET, POST }` from `toNextJsHandler(auth)`.

5. Create `apps/web/lib/auth-client.ts`:
   - Use `createAuthClient` from `better-auth/react`.
   - Register `anonymousClient()` and `jwtClient()` plugins.
   - Export `{ signIn, signOut, useSession }` and `authClient`.

6. Create `apps/web/tests/auth/auth-server.test.ts`:
   - Verify `auth` instance is initialized with plugins `anonymous` and `jwt`.
   - Verify JWT generation signs a token containing `userId` and `isAnonymous` claims that verifies with `BETTER_AUTH_SECRET` via `jose.jwtVerify`.
</action>

</read_first>
<action>
1. Create `apps/web/app/providers.tsx`:
   - Mark as `'use client'`.
   - Define `AuthContextValue`:
     ```typescript
     interface AuthContextValue {
       session: any;
       user: any;
       isAnonymous: boolean;
       isLoading: boolean;
       getToken: () => Promise<string | null>;
       signInWithGithub: () => Promise<void>;
       signOut: () => Promise<void>;
     }
     ```
   - In `AuthProvider`:
     - Hydrate session using `useSession()`.
     - In an effect, if `!isPending && !sessionData?.session`, invoke `authClient.signIn.anonymous()` to establish guest session without forced login prompts (AUTH-02, D-04, D-06).
     - Guard against generation loops: only call `signIn.anonymous()` once when no session exists.
     - Implement `getToken()` with memoized token retrieval from `authClient.token()` (with cached token fallback).
     - Implement `signInWithGithub()` using `authClient.signIn.social({ provider: 'github', callbackURL: window.location.href })`.
     - Implement `signOut()`: revokes session via `authClient.signOut()`, immediately calls `authClient.signIn.anonymous()`, and redirects to default showcase workspace (D-15).
     - Export `useAuth()` hook throwing if used outside `AuthProvider`.

2. Update `apps/web/app/layout.tsx`:
   - Import `AuthProvider` from `@/app/providers`.
   - Wrap `{children}` inside `<AuthProvider>`.

3. Create `apps/web/tests/auth/anonymous-session.test.ts`:
   - Unit test `AuthProvider` behavior:
     - When session is null and not loading, triggers `authClient.signIn.anonymous`.
     - When session contains `user.isAnonymous: true`, `isAnonymous` returns true.
     - `getToken()` returns signed Bearer token.
</action>
