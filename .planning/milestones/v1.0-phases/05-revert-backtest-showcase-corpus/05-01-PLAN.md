</read_first>
<action>
1. Create `packages/eval/src/metrics/calculator.ts` conforming to D-01, D-02, and formulas in Research §5.5:
   - `calculateCaseResult(params: { caseId: string; method: EvaluationMethod; retrievedIds: string[]; groundTruthIds: string[]; supersededIds: string[]; latencyMs: number }): CaseResult`:
     - Computes `hitAt1` (top 1 contains ground truth), `hitAt3` (top 3 contains ground truth), `hitAt5` (top 5 contains ground truth) per D-01, D-02.
     - Computes `reciprocalRank` (`1 / rank` where `rank` is 1-based index of first ground truth hit, or 0 if none found).
     - Computes `supersededHit` (`true` if top 5 contains any ID from `supersededIds`).
   - `calculateSummary(method: EvaluationMethod, results: CaseResult[]): MethodSummary`:
     - Safely handles empty input arrays (returns all zeros without NaN/division by zero).
     - Aggregates `recallAt1`, `recallAt3`, `recallAt5`, `mrr`, `supersededRate`, and `avgLatencyMs`.
2. Create `packages/eval/fixtures/reverts.json` containing 24 curated golden fixture cases conforming to D-04 and D-12 across the showcase workspaces:
   - 8 synthetic microservice cases (`synthetic-demo`): including Revert #42 (Retry Storm reverting linear backoff in favor of DEC-002 exponential jitter), Auth token expiry revert, Sync quarantine governance, Gateway timeout reverts.
   - 10 real-world Ember RFC cases (`ember-adr-showcase`): real historical reverts touching Glimmer components, tracked properties, routing transitions, Ember Data adapter changes, with verified ground truth RFC IDs and superseded RFC IDs.
   - 6 Argon dogfood cases (`argon-dogfood`): monorepo structure, FalkorDB vector dimension changes, citation validator fail-closed rule.
   - All entries must strictly validate against `RevertFixtureItemSchema` with valid UTC epoch seconds (between `1400000000` and `1780000000`).
3. Write unit tests:
   - `packages/eval/test/metrics.test.ts`: tests `calculateCaseResult` and `calculateSummary` on edge cases (zero results, immediate top 1 hit, hit at rank 3, hit at rank 5, no hit, superseded contamination, rank ties).
   - `packages/eval/test/fixtures.test.ts`: loads `packages/eval/fixtures/reverts.json` and asserts all 24 cases pass `RevertFixtureItemSchema.parse()`, have non-empty `groundTruthDecisionIds`, valid epoch timestamps, and unique `caseId` values.
</action>
