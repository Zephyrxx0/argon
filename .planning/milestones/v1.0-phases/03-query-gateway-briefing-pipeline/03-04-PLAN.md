### ASVS Level 1 Controls & Threat Mitigations

| Threat ID | Threat Description | ASVS Control | Mitigation in this Plan |
|---|---|---|---|
| **T-03-04** | Graph Poisoning / Grounding Bypass via Fabricated Citation IDs: Narration model generates plausible IDs not returned in retrieval evidence, fabricating artificial consensus or lineage. | **ASVS V5.3.1** (Verify data integrity and foreign entity references) | The validator checks all `citedNodeIds` against the in-memory retrieval evidence set, with a single-record FalkorDB fallback check. Any claim item referencing an unverified ID is unconditionally stripped per D-13 and CITE-01. |
| **T-03-11** | Deceptive Grounding / False Architecture Confidence: If all claims are stripped due to invalid citations, presenting an empty shell suggests the system found nothing wrong. | **ASVS V5.1.2** (Fail secure and explicit error states) | If citation stripping leaves 0 verified claims in the briefing, the validator activates the "no graph, no answer" refusal, returning status `CITATION_INTEGRITY_FAILURE` with a clear diagnostic explanation per D-14. |
| **T-03-12** | Cypher Injection in Write-Back Memory: Malicious or untrusted strings in task text or briefing summaries manipulate Cypher write commands during `record_outcome`. | **ASVS V5.3.4** (Strict parameterized query execution) | Write-back memory uses strictly parameterized Cypher statements via `ArgonGraphClient.query` (`CREATE (b:Briefing { id: $id, ... })`), preventing any user text interpolation into Cypher grammar per D-15. |
</threat_model>

2. In `packages/agent/src/memory/record-outcome.ts`:
   - Implement `recordOutcome(graphClient: ArgonGraphClient, params: RecordOutcomeParams): Promise<RecordOutcomeResult>` conforming to D-15 and D-16:
   - Generate unique briefing ID: `const briefingId = randomUUID()`.
   - Capture current timestamp: `const createdAt = Date.now()`.
   - Resolve actor: `const effectiveActor = params.contributorId ?? params.actorId ?? 'anonymous'`.
   - Construct parameterized Cypher write transaction:
     ```cypher
     CREATE (b:Briefing {
       id: $briefingId,
       task: $task,
       summary: $summary,
       actorId: $actorId,
       created_at: $createdAt,
       scope_hash: $scopeHash
     })
     WITH b
     UNWIND $citedNodeIds AS citedId
     OPTIONAL MATCH (target) WHERE target.id = citedId OR target.path = citedId OR target.name = citedId
     FOREACH (_ IN CASE WHEN target IS NOT NULL THEN [1] ELSE [] END |
       CREATE (b)-[:CITES]->(target)
     )
     WITH b
     UNWIND $components AS compName
     OPTIONAL MATCH (c:Component { name: compName })
     FOREACH (_ IN CASE WHEN c IS NOT NULL THEN [1] ELSE [] END |
       CREATE (b)-[:ABOUT]->(c)
     )
     WITH b
     OPTIONAL MATCH (p:Person { id: $contributorId })
     FOREACH (_ IN CASE WHEN p IS NOT NULL THEN [1] ELSE [] END |
       CREATE (p)-[:REQUESTED]->(b)
     )
     RETURN b.id AS id;
     ```
   - Execute via `graphClient.query(params.workspaceId, cypher, parameters)`.
   - Return `{ briefingId, createdEdges: ... }`.
