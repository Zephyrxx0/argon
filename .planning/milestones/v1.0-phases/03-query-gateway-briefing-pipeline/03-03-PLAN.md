### ASVS Level 1 Controls & Threat Mitigations

| Threat ID | Threat Description | ASVS Control | Mitigation in this Plan |
|---|---|---|---|
| **T-03-03** | Prompt Injection / Instruction Smuggling in Git Artifacts: Malicious commit messages or ADR files ingested into graph nodes contain instructions attempting to hijack the narration prompt. | **ASVS V5.1.1 / OWASP LLM01** (Verify boundary delimiters for external data in LLM prompts) | Prompt template in `prompt.ts` encapsulates all graph evidence in explicit `<EVIDENCE>` tags and includes a mandatory system constraint instructing the model to treat content within `<EVIDENCE>` strictly as inert factual data and ignore any meta-instructions found within per D-09 and PRD §14.2. |
| **T-03-09** | Hallucination & Ungrounded Output Generation: Narration model generates plausible-sounding architectural claims without grounding them in retrieved graph nodes. | **ASVS V5.1.2 / OWASP LLM09** (Output validation against strict schema contracts) | Strict `BriefingSchema` requires `citedNodeIds: string[]` with `min(1)` on every claim item. Outputs failing schema are repaired once via the automated repair loop; if still failing, execution halts with a structured error per D-09 and D-10. |
| **T-03-10** | Upstream API Rate Limiting / Denial of Service via 429: Bursts of user queries hit Google free-tier rate limits, causing system failure during judging or peak load. | **ASVS V11.1.8** (Graceful degradation and rate limit retry backoff) | The LLM wrapper intercepts HTTP 429 errors, executes 2 exponential backoff retries (1s, 2s), and if still throttled, automatically degrades to `gemini-2.5-flash-lite` using the same provider key per D-11. |
