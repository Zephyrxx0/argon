<objective>
Build the core `packages/graph` database client and schema foundation. Implement `ArgonGraphClient` with connection pooling, 5000ms query timeouts, typed `FalkorUnavailableError` ("no graph, no answer" refusal contract), and strict read-only query dispatch (`roQuery`). Author `schema.cypher` defining nodes, relationships, uniqueness constraints, and the 512-d cosine vector index on `Decision.embedding`. Implement programmatic idempotent initialization via `initWorkspaceGraph(workspaceId)` and verify against live FalkorDB via Vitest.

Purpose: Establishes the authoritative database interface and knowledge graph structure required for ingestion, vector search, and briefing queries.
Output: `packages/graph` package with `ArgonGraphClient`, `schema.cypher`, idempotent initializer, CLI migration tool, and integration tests.
</objective>

## Artifacts this phase produces

This plan creates the core graph database client, schema definitions, and idempotent initialization logic:

### Classes & Errors
- `ArgonGraphClient`: Core FalkorDB client wrapper with connection pooling, 5000ms timeouts, and strict read-only query dispatch (`packages/graph/src/client.ts`)
- `FalkorUnavailableError`: Typed error class signaling FalkorDB unavailability ("no graph, no answer" refusal contract) (`packages/graph/src/client.ts`)

### Functions & Utilities
- `initWorkspaceGraph`: Idempotent schema initialization function configuring range indexes, uniqueness constraints, and 512-d vector index (`packages/graph/src/schema/init.ts`)

### CLI Commands & Scripts
- `pnpm --filter @argon/graph db:schema:apply`: CLI script to apply schema migrations to a specified workspace (`packages/graph/src/schema/apply.ts`)
- `pnpm --filter @argon/graph test:integration`: Runs FalkorDB integration tests against live database
- `pnpm --filter @argon/graph test`: Runs Vitest test suite

### Graph Schema Elements (`packages/graph/src/schema/schema.cypher`)
- Node Labels: `Person`, `Component`, `File`, `PullRequest`, `Issue`, `Decision`, `Briefing`, `IngestJob`
- Relationship Types: `AUTHORED`, `REVIEWED`, `TOUCHES`, `IN_COMPONENT`, `DEPENDS_ON`, `GOVERNS`, `SUPERSEDES`, `EXTRACTED_FROM`, `REVERTS`, `FAMILIAR_WITH`, `CITES`, `ABOUT`
- Vector Index: `CREATE VECTOR INDEX FOR (d:Decision) ON (d.embedding) OPTIONS {dimension: 512, similarityFunction: 'cosine'}`
- Uniqueness Constraints: `Person.id`, `Component.name`, `File.path`, `PullRequest.number`, `Decision.id`, `IngestJob.id`

### Files Created
- `packages/graph/package.json`: Manifest for `@argon/graph` package
- `packages/graph/tsconfig.json`: TypeScript configuration extending `@argon/tsconfig/node.json`
- `packages/graph/vitest.config.ts`: Vitest test configuration with node environment and timeouts
- `packages/graph/src/client.ts`: `ArgonGraphClient` and `FalkorUnavailableError` implementation
- `packages/graph/src/schema/schema.cypher`: Complete reference Cypher DDL for schema and vector index
- `packages/graph/src/schema/init.ts`: Idempotent programmatic schema initializer
- `packages/graph/src/schema/apply.ts`: CLI entrypoint for workspace graph schema initialization
- `packages/graph/src/index.ts`: Package entrypoint exporting client, error, and schema init
- `packages/graph/test/setup.ts`: Environment configuration and test setup for Vitest
- `packages/graph/test/schema.test.ts`: Integration test suite for client connectivity, refusal errors, and schema idempotency

1. Implement `packages/graph/src/client.ts`:
   - Define custom error class `FalkorUnavailableError`:
     ```typescript
     export class FalkorUnavailableError extends Error {
       constructor(message: string, public readonly cause?: unknown) {
         super(`[NO GRAPH, NO ANSWER] FalkorDB is unavailable: ${message}`);
         this.name = 'FalkorUnavailableError';
       }
     }
     ```
   - Implement `ArgonGraphClient`:
     * Constructor accepts `config?: { url?: string; defaultTimeoutMs?: number }`. Defaults URL to `process.env.FALKORDB_URL ?? 'falkor://localhost:6379'` and timeout to 5000ms.
     * `connect()` method connects via `FalkorDB.connect({ url, socket: { connectTimeout: timeoutMs } })`. Ensures RESP 2 protocol is maintained (default in `falkordb`). Catches socket / network errors and throws `FalkorUnavailableError`.
     * `getRawClient(): FalkorDB` returns connected client or throws `FalkorUnavailableError('Client not connected')`.
     * `selectGraph(workspaceId: string)` returns the workspace graph instance.
     * `roQuery<T = unknown>(workspaceId: string, cypher: string, params: Record<string, unknown> = {}, timeoutMs?: number): Promise<T>` executes `graph.roQuery<T>(cypher, { params, TIMEOUT: timeoutMs ?? this.defaultTimeoutMs })`. Catches ECONNREFUSED or connection lost and re-throws as `FalkorUnavailableError`.
     * `query<T = unknown>(workspaceId: string, cypher: string, params: Record<string, unknown> = {}, timeoutMs?: number): Promise<T>` for mutations (schema init and worker writes only).
     * `ping(): Promise<boolean>` verifies connectivity with health ping.
     * `close(): Promise<void>` closes connection cleanly.

2. Export client and error from `packages/graph/src/index.ts`.
