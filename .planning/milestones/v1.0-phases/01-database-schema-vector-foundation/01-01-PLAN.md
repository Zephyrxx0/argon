## Artifacts this phase produces

This plan creates foundational configuration, shared workspace packages, and local container orchestration:

### Files Created
- `pnpm-workspace.yaml`: Root workspace definition configuring `apps/*` and `packages/*`
- `turbo.json`: Turborepo build pipeline configuration (`build`, `typecheck`, `lint`, `test`, `dev`)
- `package.json`: Root package manifest with workspace-wide lifecycle and database orchestration scripts
- `.gitignore`: Git exclusion patterns for monorepo build outputs, node_modules, and FalkorDB data volumes
- `packages/tsconfig/package.json`: `@argon/tsconfig` package manifest
- `packages/tsconfig/base.json`: Base TypeScript configuration with NodeNext module resolution and strict checks
- `packages/tsconfig/nextjs.json`: Next.js 15 TypeScript configuration with bundler resolution and JSX preserve
- `packages/tsconfig/node.json`: Node.js TypeScript configuration with NodeNext resolution
- `apps/web/package.json`: Next.js 15 web application package manifest referencing `@argon/graph` workspace package
- `apps/web/tsconfig.json`: Web app TypeScript configuration extending `@argon/tsconfig/nextjs.json`
- `apps/web/next.config.ts`: Next.js configuration enabling `transpilePackages: ['@argon/graph']`
- `apps/web/postcss.config.mjs`: PostCSS configuration for Tailwind CSS v4
- `apps/web/app/globals.css`: Tailwind CSS v4 styling and brutalist cyberpunk theme tokens
- `apps/web/app/layout.tsx`: Root HTML layout with metadata and dark theme styling
- `apps/web/app/page.tsx`: Landing view with brutalist system status dashboard
- `docker-compose.yml`: Local container definition for FalkorDB with automated healthchecks

### CLI Commands & Scripts
- `pnpm build`: Runs Turborepo build across all workspaces
- `pnpm dev`: Runs Turborepo development servers
- `pnpm lint`: Runs Turborepo lint tasks
- `pnpm test`: Runs Turborepo test suites
- `pnpm typecheck`: Runs Turborepo typecheck tasks
- `pnpm db:up`: Starts FalkorDB Docker container in detached mode
- `pnpm db:down`: Stops FalkorDB Docker container
- `pnpm db:healthcheck`: Automated healthcheck validating FalkorDB container readiness

### Components & Symbols
- `RootLayout`: Root Next.js application layout component (`apps/web/app/layout.tsx`)
- `HomePage`: Root page component (`apps/web/app/page.tsx`)
