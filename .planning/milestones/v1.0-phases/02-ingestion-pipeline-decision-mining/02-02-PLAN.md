    1. In `packages/ingest/src/coupling/cochange.ts`, implement `computeCoChangeCoupling(commits: GitCommit[], options?: CouplingOptions)`:
       - Default options: `minCoCommits = 3`, `minJaccard = 0.15`, `maxFilesPerCommit = 30` conforming to D-06.
       - Discard commits modifying more than `maxFilesPerCommit` files (filters formatting, license updates, large merges).
       - Filter modified files using `isArchitecturalFile`.
       - Track individual file commit frequencies: `fileCommitCount: Map<string, number>`.
       - Track pair-wise file co-occurrences: `pairCoCommitCount: Map<string, number>` (ordered key `${fileA}::${fileB}`).
       - Compute file-to-component mapping for all files using `deriveComponents`.
       - For each pair with `coCommits >= minCoCommits`:
         - Calculate Jaccard similarity: `J(A, B) = count(A & B) / (count(A) + count(B) - count(A & B))`.
         - If `J(A, B) >= minJaccard`, record a file-level coupling edge.
       - Aggregate component-to-component coupling:
         - When files $A \in C_1$ and $B \in C_2$ ($C_1 \neq C_2$) co-change, accumulate shared commits between components.
         - Normalize component-level Jaccard similarity: `J(C1, C2) = count(C1 & C2) / (count(C1) + count(C2) - count(C1 & C2))`.
         - If `coCommits >= minCoCommits` and `J >= minJaccard`, produce a `CoChangeEdge` representing `(:Component)-[:DEPENDS_ON {weight: jaccard, count: coCommits}]->(:Component)` conforming to ING-02.

       - Assert that lockfiles are ignored.
       - Assert that pairs with $< 3$ co-commits or $Jaccard < 0.15$ are filtered out.
       - Assert that valid cross-component couplings correctly yield `[:DEPENDS_ON]` edges with expected weight and count.
  </action>
