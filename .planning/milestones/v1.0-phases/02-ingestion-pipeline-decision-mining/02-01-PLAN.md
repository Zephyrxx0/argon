## Artifacts this phase produces

This plan scaffolds `packages/ingest` and implements git extraction capabilities:

### Files Created
- `packages/ingest/package.json`: Package manifest defining dependencies on `@argon/graph`, `simple-git`, and shared tooling
- `packages/ingest/tsconfig.json`: TypeScript configuration extending `@argon/tsconfig/node.json`
- `packages/ingest/vitest.config.ts`: Vitest test configuration
- `packages/ingest/src/git/types.ts`: TypeScript contracts for `GitCommit`, `GitFile`, `GitAuthor`, `ExtractedRepoData`
- `packages/ingest/src/git/clone.ts`: `cloneRepository` function implementing blobless clone and cleanup
- `packages/ingest/src/git/log.ts`: `extractCommits` function streaming commit history and file diffs
- `packages/ingest/src/git/author.ts`: `parseMailmap`, `resolveAuthor`, and `hashAuthorEmail` functions
- `packages/ingest/src/index.ts`: Public API exports for `@argon/ingest`
- `packages/ingest/test/git.test.ts`: Vitest suite testing git extraction against a local programmatic git repository

### Functions & Interfaces
- `cloneRepository(repoUrl: string, options?: CloneOptions): Promise<CloneResult>`

- `extractCommits(repoPath: string, options?: LogOptions): Promise<ExtractedRepoData>`
- `hashAuthorEmail(email: string): string`
- `parseMailmap(mailmapContent: string): Map<string, CanonicalAuthor>`
- `resolveAuthor(rawName: string, rawEmail: string, mailmap?: Map<string, CanonicalAuthor>): ResolvedAuthor`
- `GitCommit`, `GitAuthor`, `GitFileChange`, `ExtractedRepoData` interfaces
