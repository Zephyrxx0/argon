<objective>
Implement architectural decision mining, git revert extraction, temporal window management, and batched decision embedding in `packages/ingest/src/mining`. The module parses markdown ADRs/RFCs, identifies commit-level architectural decisions and revert pairs, enforces `valid_from` / `valid_to` epoch timestamps and `[:SUPERSEDES]` relationships, and embeds decision texts using `@argon/graph`'s `ArgonEmbedder`.

Purpose: Populates the knowledge graph with architectural decisions, git reverts, and 512-d vector embeddings, fulfilling requirements DEC-01, DEC-02, and ING-03.
Output: Working ADR parser, revert miner, commit decision extractor, decision vectorizer, and Vitest suite in `packages/ingest/test/mining.test.ts`.
</objective>

## Artifacts this phase produces

This plan implements decision mining, revert pairing, and vectorization:

### Files Created
- `packages/ingest/src/mining/types.ts`: TypeScript contracts for `MinedDecision`, `RevertLink`, `SupersessionLink`, `MinedData`
- `packages/ingest/src/mining/adr.ts`: Glob scanner and markdown parser for ADRs, RFCs, and architecture docs
- `packages/ingest/src/mining/reverts.ts`: Git revert commit matcher linking reverted pull requests
- `packages/ingest/src/mining/commits.ts`: Regex heuristic commit decision classifier
- `packages/ingest/src/mining/embed.ts`: Decision batch embedder reusing `ArgonEmbedder` from `packages/graph`
- `packages/ingest/test/mining.test.ts`: Vitest suite asserting markdown ADR parsing, revert pairing, temporal window calculation, and vector generation
