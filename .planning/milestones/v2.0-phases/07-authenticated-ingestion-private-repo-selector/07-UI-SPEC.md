## Visuals & Hierarchy

- **Primary Visual Anchor / Focal Point:** The enhanced `IngestModal` dialog featuring a two-tab navigation header (`Your Repositories` vs `Public URL`) with live installation status, instant fuzzy filtering, and responsive repository list rows.
- **Repository List Row Architecture (D-10):**
  1. *Leading:* Organization/owner avatar (24x24px rounded-sm border border-border) with fallback monospace initials.
  2. *Title & Branch:* Repository slug (`owner/repo`) in high-contrast monospace bold (`#e6edf3`), paired with a default branch badge (`main`/`master`) in muted styling.
  3. *Visibility & Trailing Action:* Private lock badge (yellow/amber `#ffb800` or muted cyan) or Public globe badge, and a high-contrast "Index" action button that triggers the pipeline.
- **Organization Filter Strip (D-11):** Horizontal filter pills immediately below the search bar (`All`, `Personal`, `org-name`) allowing instant scope narrowing across multiple installations.
- **Contributor Identity Attribution (D-16, TENANT-02):**
  1. *ContributorPicker:* Verified contributors display small GitHub avatar next to name, with a distinctive cyan pill badge `[YOU]` when matching the active authenticated session.
  2. *NodeInspector:* Inspecting a `(:Person)` node reveals an enriched header card with GitHub profile link (`github.com/login`), verified badge (`ShieldCheck` icon), and primary commit count.
