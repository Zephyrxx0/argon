# Plan 07-01: Secret-Scrubbed Authenticated Ingestion Pipeline

> Implement secret redaction, credential-free git transport via `http.extraheader`, sanitized error codes, and canary leak tests in `packages/ingest`.

---

## Objective

Equip `packages/ingest` with secure, leak-proof private repository cloning. Ensure credentials never appear in git remote URLs, `.git/config`, stdout/stderr process output, log streams, or FalkorDB `(:IngestJob.error)` fields, backed by rigorous canary leak verification tests (ING-05, ING-04).

---

## Threat Model (ASVS Level 1)

<threat_model>
| Threat ID | Category (STRIDE) | Description | Severity | Mitigation Task | Verification |
|-----------|-------------------|-------------|----------|-----------------|--------------|
| T-07-01 | Information Disclosure | Git remote origin contains embedded token (`https://token@github.com`), persisting on disk in `.git/config` and exposed in `git remote -v` | High | Task 07-01-02 | Assert remote URL remains `https://github.com/owner/repo` without credentials |
| T-07-02 | Information Disclosure | Subprocess stdout/stderr or thrown exception leaks installation token to terminal or FalkorDB `(:IngestJob.error)` | High | Task 07-01-01 & Task 07-01-03 | Canary test injects `ghs_canary_*` token and asserts zero occurrences |
| T-07-03 | Elevation of Privilege / Tampering | Malformed git options allow command injection via CLI arguments | High | Task 07-01-02 | Explicit argument arrays passed to SimpleGit, rejecting shell string concatenation |
</threat_model>

---

## Must Haves

<must_haves>
### Truths
- `redactSecrets(input)` masks `ghs_*`, `ghp_*`, `gho_*`, `ghu_*`, `ghr_*`, `github_pat_*`, `Bearer ...`, `Basic ...`, and `x-access-token:...` strings into `[REDACTED_SECRET]`.
- `cloneRepository(url, { installationToken })` injects `-c http.extraheader=Authorization: Basic ...` keeping remote URL clean.
- Git authentication failure maps to structured sanitized error code `AUTH_FAILED_EXPIRED_OR_REVOKED` without exposing raw stack traces or tokens.
- FalkorDB `writeIngestJob()` applies `redactSecrets()` to the `error` property when recording failed jobs.
- Integration test suite passes canary secret leak verification asserting zero occurrences of canary token in logs, job properties, or error streams.

### Prohibitions
- NEVER embed credentials or access tokens directly into git clone URLs.
- NEVER write unredacted stdout/stderr streams to console logs or FalkorDB node properties.
- NEVER accept installation tokens via command-line flags or environment variables in `packages/ingest`.
</must_haves>

### Task 07-01-01: Implement Centralized Secret Redaction & Sanitization Utility (Wave 1)

<task id="07-01-01" type="tracer">
<read_first>

- packages/ingest/src/writer/falkordb.ts
- .planning/phases/07-authenticated-ingestion-private-repo-selector/07-CONTEXT.md (D-06, D-07)
</read_first>
<action>
Create `packages/ingest/src/git/redact.ts` exporting:
1. `SECRET_PATTERNS`: regex patterns matching:
   - `ghs_[A-Za-z0-9_]{20,}` (GitHub App installation tokens)
   - `ghp_[A-Za-z0-9_]{20,}` (Personal access tokens)
   - `gho_[A-Za-z0-9_]{20,}` (OAuth access tokens)
   - `ghu_[A-Za-z0-9_]{20,}` (User-to-server tokens)
   - `ghr_[A-Za-z0-9_]{20,}` (Refresh tokens)
   - `github_pat_[A-Za-z0-9_]{20,}` (Fine-grained PATs)
   - `Bearer\s+[A-Za-z0-9_.-]+`
   - `Basic\s+[A-Za-z0-9+/=]+`
   - `https:\/\/[^@\s]+@` -> replaces credential prefix with `https://`
   - `x-access-token:[^@\s]+@`
2. `redactSecrets(input: string): string`: Iterates over `SECRET_PATTERNS` replacing occurrences with `[REDACTED_SECRET]`.
3. `sanitizeError(err: unknown): Error`: Returns a new `Error` with `message` and `stack` passed through `redactSecrets`.
4. `createSanitizedAuthError(originalError: unknown): Error`: Detects git 401/403 authorization failures and constructs an error with message: `"AUTH_FAILED_EXPIRED_OR_REVOKED: GitHub installation token expired or permissions revoked — please re-authorize GitHub App"`.
5. Update `packages/ingest/src/writer/falkordb.ts` where `(:IngestJob)` errors are written to wrap error strings with `redactSecrets()`.
</action>
<acceptance_criteria>
- `redactSecrets("Cloning with ghs_1234567890abcdefghijklmnop")` returns `"Cloning with [REDACTED_SECRET]"`.
- `redactSecrets("https://x-access-token:ghs_secret@github.com/org/repo")` returns `"https://github.com/org/repo"`.
- `sanitizeError(new Error("Failed ghp_personalSecretToken12345"))` returns Error with redacted message.
- `createSanitizedAuthError(...)` produces message starting with `"AUTH_FAILED_EXPIRED_OR_REVOKED"`.
- Unit tests in `packages/ingest/test/git/redact.test.ts` pass cleanly.
</acceptance_criteria>
<verify>
pnpm --filter @argon/ingest test test/git/redact.test.ts
</verify>
</task>

- packages/ingest/src/pipeline.ts

</read_first>
<action>
1. In `packages/ingest/src/git/types.ts`:
   - Add `installationToken?: string` to `CloneOptions`.
2. In `packages/ingest/src/git/clone.ts`:
   - Import `redactSecrets`, `sanitizeError`, and `createSanitizedAuthError` from `./redact.js`.
   - In `cloneRepository(repoUrl, options)`:
     - If `options.installationToken` is provided, encode credentials as `Buffer.from(`x-access-token:${options.installationToken}`).toString('base64')`.
     - Inject `cloneArgs.unshift('-c', `http.extraheader=Authorization: Basic ${credentials}`)`.
     - Ensure `normalizedUrl` is clean (`https://github.com/org/repo` without any in-URL tokens).
     - Wrap `git.clone` in a try/catch block. On error:
       - Check if message contains `Authentication failed`, `HTTP 401`, or `HTTP 403`.
       - If auth failure, throw `createSanitizedAuthError(err)`.
       - Otherwise, throw `sanitizeError(err)`.
3. In `packages/ingest/src/pipeline.ts`:
   - Add `installationToken?: string` to `IngestConfig`.
   - Pass `installationToken: config.installationToken` to `cloneRepository()`.
</action>
