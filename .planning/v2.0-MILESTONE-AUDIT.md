# Milestone Audit: Argon v2.0 (GitHub App Integration & Incremental Sync)

**Audited:** 2026-10-16  
**Status:** **GAPS FOUND**  
**Core Value:** Every briefing claim is mathematically grounded in and computed by the FalkorDB knowledge graph (traversals, PageRank/centrality, temporal predicates, and vector search) with 100% citation integrity—"no graph, no answer."

---

## 1. Executive Summary

Milestone v2.0 extended Argon with GitHub OAuth, FalkorDB tenant authorization, GitHub App authenticated ingestion with secret scrubbing, and an incremental sync webhook listener with live Cytoscape SSE feedback.

All 3 phases (Phases 6, 7, and 8) achieved **PASSED** ratings in their individual unit/integration verification reports (`06-VERIFICATION.md`, `07-VERIFICATION.md`, `08-VERIFICATION.md`). The monorepo test suite passes with 100% success (55 test files, 272 tests passing).

However, an independent cross-phase integration audit by `gsd-integration-checker` revealed **3 critical cross-phase wiring gaps** preventing end-to-end execution:
1. **Frontend / Gateway Proxy Gap (ING-04):** `apps/web/next.config.ts` does not proxy `/api/v1/:path*` to Gateway (`http://localhost:8080`), causing browser fetch calls from `RepoPicker` to return `404 Not Found`.
2. **Ingestion Runner Hook Gap (ING-04, TENANT-02):** In `apps/gateway/src/app.ts`, `githubRoute` is mounted without an `onIngest` callback, so calling `POST /api/v1/github/ingest` registers workspace permissions in FalkorDB but never triggers `runIngestion` or `linkUserToPersonIdentities`.
3. **SSE Connection Prop Gap (SYNC-03):** In `apps/web/app/page.tsx`, `<GraphSyncProvider>` is instantiated without passing `workspaceId` or `token`. Consequently, `useGraphSync` aborts SSE stream initialization (`if (!workspaceId) return`), preventing live Cytoscape canvas pulse animations, HUD indicators, and stale briefing banners from receiving events in production.

In addition, an unprotected route in `apps/web/app/api/briefing/route.ts` bypasses tenant authorization when querying workspaces directly.

1. **Guest / Authenticated Briefing Flow (AUTH-01, AUTH-02, TENANT-01):**
   - **Status:** **PARTIAL (Security Warning)**
   - Gateway correctly enforces 401/403 access control. However, Next.js internal `/api/briefing/route.ts` ignores tenant verification and Bearer tokens, executing graph queries as admin or direct FalkorDB client.

2. **Searchable Repository Selection & Ingestion Flow (ING-04, ING-05, TENANT-02):**
   - **Status:** **BROKEN (BLOCKER)**
   - User opens Ingest Modal and selects a repository. `RepoPicker` fetches `/api/v1/github/repositories` which 404s without Next.js URL rewrite. Even if triggered, `POST /api/v1/github/ingest` creates workspace access but does not invoke `runIngestion`, leaving git clone and contributor identity linking unexecuted.

3. **Webhook Delivery to Real-Time Canvas Pulse Flow (SYNC-01, SYNC-02, SYNC-03):**

However, `<GraphSyncProvider>` in `apps/web/app/page.tsx` is rendered without `workspaceId` or `token`, so `EventSource` is never connected in the browser. Canvas pulse animations, HUD indicators, and stale briefing banners remain inert.
