## 4. End-to-End User Flows

1. **Ingestion to Graph Flow:** Shallow clone -> author SHA-256 pseudonymization -> component co-change coupling -> revert commit mining -> ADR/RFC temporal window assignment -> 512-d Matryoshka vectorization -> UNWIND batch database commit. **(PASSED)**
2. **Gateway & Agent to Graph Flow:** Authenticated Bearer gateway dispatch -> parallel multi-query retrieval (`blastRadius`, `whoKnows`, `constrainingDecisions`, `precedentSearch`) -> Gemma 4 structured narration -> 100% citation verification -> `(:Briefing)` graph write-back memory. **(PASSED)**
3. **Web App to Gateway/Agent Flow:** Unified command bar (`Cmd+K`) -> Next.js API route -> client auto-selection (`HttpGatewayClient` vs `DirectGraphGatewayClient`) -> left panel Briefing View stream -> right panel Cytoscape.js interactive canvas with bidirectional highlighting. **(PASSED)**
4. **Evaluation & Backtest Flow:** Parameterized openCypher `$asOf` predicate rewinding -> 24 golden fixtures in `fixtures/reverts.json` -> comparative evaluation against flat vector RAG and raw LLM baselines -> export to `eval-report.json`, Markdown tables, and ANSI CLI output. **(PASSED)**
5. **Refusal Kill-Switch Flow ("No Graph, No Answer"):** Unreachable database or integrity failure -> pipeline fails closed (`NO_GRAPH_DATA` / `CITATION_INTEGRITY_FAILURE`) -> `KillSwitchCard` renders cyberpunk alert banner with refusal reason and "Test DB Connection" retry trigger. **(PASSED)**

## 6. Identified Tech Debt & Non-Blocking Notes

1. **Docker Runtime Gating (Phase 1):** In offline sandboxed environments without a running Docker daemon, all test suites and CLI tools feature graceful fallback simulation/mock gates. In production, Docker Compose (`pnpm db:up`) and `pnpm seed:showcase` orchestrate live FalkorDB.
2. **Next.js Standalone Container Output (Phase 4):** `output: 'standalone'` can be toggled in `apps/web/next.config.ts` if containerizing the web frontend for Google Cloud Run deployment.
3. **Dual Client Configuration:** `apps/web` works seamlessly in both standalone monorepo development mode and distributed microservice deployment mode via the `GATEWAY_URL` environment toggle.
